# 网页题目助手（Microsoft Edge）

一个本地安装的 Manifest V3 扩展。用户主动启动整页滚动截图；视觉模型定位每道题后，扩展在本地将长图像素裁成独立题目截图。用户检查并确认选题后，扩展才会按题号顺序逐张上传裁切图并请求解答。

## 在 Edge 中安装

1. 解压下载的 ZIP；Edge 加载的是解压后的扩展文件夹。
2. 打开 `edge://extensions` 并启用“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的文件夹。
4. 点击工具栏中的“网页题目助手”图标打开扩展。

## 配置 API

1. 在扩展弹窗点击“设置”。
2. 填写 API 地址、明确支持视觉输入的模型名称和 API Key，然后保存。
3. 默认地址为 `https://api.deepseek.com/chat/completions`。兼容服务还必须支持 Chat Completions 的 `image_url` 图像消息格式。
4. 第一次访问 API 主机时，Edge 会要求授予该主机的访问权限。API 地址必须使用 HTTPS；只有本机 `localhost` 可使用 HTTP。

DeepSeek 兼容服务和各模型的视觉能力不同。请确认所选模型支持图像输入；纯文本模型不能处理截图。API Key 保存在扩展本地存储，不写入结果记录、网页或新标签页地址；可在设置页清除。

## 使用流程与隐私

1. 在目标网页打开扩展，点击“截取整页长图”。扩展滚动页面并拼接可见视口截图，完成或取消后尝试恢复原滚动位置。期间显示进度并可取消。
2. 点击“识别并切分题目截图”后会打开结果标签页。**题目定位阶段会将完整整页长截图发送给视觉 API**，要求模型返回题号及相对于长图的归一化矩形坐标；该请求用于定位，不用于解题。模型无法保证准确识别所有题目，尤其是过长、文字过小或多栏页面。
3. 扩展按返回坐标在本地 canvas 对长图做真实像素裁切，并展示每道题的独立截图。在确认界面中可直接拖动原长图上的题目框来移动区域，拖动四边或四角手柄来调整大小；支持鼠标和触屏。裁切预览会同步更新。也可在整页截图的空白处开启“框选新增题目”并拖出矩形，修改题号、删除题目，或取消勾选不需要解答的题目。题目框会限制在长图边界内，并保留最小可用宽高。
4. 检查最终题目截图后，只有点击“确认并逐题求解”才会按题号顺序逐张发送当前选中的最终裁切图。求解请求不会附带整页长截图。结果页按题号将裁切图与对应解答放在一起；可以取消后续题目，或重试失败题目。

确认前不会向 API 发送任何逐题裁切图用于解答；但是识别定位所需的整页截图已在步骤 2 发给该服务。若不希望服务接触页面上的非题目信息，请勿对该页面启动识别。完整长图和裁切图均保存在扩展本地 IndexedDB 结果记录中，不会写入网页网站的数据存储；最近 5 份记录会保留。

扩展不读取网页文字、表单值或隐藏内容；注入页面的脚本仅用于读取尺寸、滚动和恢复位置。只处理当前标签页可见画面。Edge 内部页面、扩展商店等受限页面可能禁止截图或脚本注入；嵌套滚动区域、跨源嵌入内容和动态页面也可能无法完整采集。

## 运行裁切编辑器回归测试

`crop-editor.test.html` 使用合成截图和模拟 API，不会访问外部服务。可在 Windows PowerShell 中用 Edge 打开（将示例路径替换为扩展目录的实际路径）；完成后页面会显示测试结果：

```powershell
& "${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe" --allow-file-access-from-files "file:///C:/path/to/edge-question-helper/crop-editor.test.html?id=crop-test"
```

测试覆盖坐标映射、触屏指针拖动/缩放、边界约束、手动新增与删除题目、裁切预览，以及最终确认前不发送逐题请求、确认后按题号上传、结果页隐私提示及行内/块级/嵌套 `\boxed` 公式 MathML 结构。
